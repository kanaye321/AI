# AI Study Lab

## Overview

AI Study Lab is a dark-light adaptive personal learning workspace. It turns a natural-language topic into a research-backed study module through an orchestrated backend pipeline, with Ollama and Tavily configured through environment variables.

## User preferences

- Dark mode is available, with light mode as the default preview theme for comfortable reading.
- Keep the interface calm, spacious, and focused on the next learning action.

## Development

Run `npm run dev` to start the Vite-powered Node server on port 5000.
